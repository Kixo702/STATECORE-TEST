# Система переключения тем (Dark/Light Mode)

## Описание
Добавлена полная система переключения между темной и светлой темой с сохранением выбора в localStorage.

## Структура

### 1. **ThemeContext** (`src/lib/ThemeContext.jsx`)
- `ThemeProvider` — обёртка для приложения, управляющая состоянием темы
- `useTheme()` — хук для использования в компонентах
- Сохраняет выбор темы в localStorage

### 2. **Интеграция в приложение** (`src/App.jsx`)
- AppContent использует `useTheme()` для применения стилей
- Динамическое переключение классов на основе выбранной темы
- Плавный переход между темами

### 3. **Тумблер** (`src/components/Topbar.jsx`)
- Кнопка переключения в верхней панели
- Иконки: ☀️ (Солнце) для светлой темы, 🌙 (Луна) для тёмной
- Состояние кнопки изменяется в зависимости от выбранной темы

### 4. **CSS переменные** (`src/index.css`)
- Переменные для обеих тем (цвета фона, текста, бордеров)
- Автоматическое применение стилей на основе класса `.light` или `.dark` на `<html>`

### 5. **Конфиг Tailwind** (`tailwind.config.js`)
- Поддержка класса `dark` с селектором `:root.dark`
- Расширенные цветовые переменные для StateCore

## Использование в компонентах

### Получение текущей темы:
```jsx
import { useTheme } from '../lib/ThemeContext'

export default function MyComponent() {
  const { theme, toggleTheme } = useTheme()
  
  return (
    <button onClick={toggleTheme}>
      Текущая тема: {theme}
    </button>
  )
}
```

### Применение стилей в зависимости от темы:
```jsx
const bgClass = theme === 'light' ? 'bg-[#f8f9fb]' : 'bg-[#090D16]'
const textClass = theme === 'light' ? 'text-[#0b0d16]' : 'text-white'

return <div className={`${bgClass} ${textClass}`}>...</div>
```

## Цветовые палитры

### Тёмная тема (по умолчанию)
- Фон: `#090D16`
- Текст: `#f2f4fb`
- Бордеры: `rgba(255, 255, 255, 0.06)`

### Светлая тема
- Фон: `#f8f9fb`
- Текст: `#0b0d16`
- Бордеры: `rgba(11, 13, 22, 0.1)`

## Функции

✅ Переключение темы через тумблер в Topbar  
✅ Сохранение выбора в localStorage  
✅ Применение стилей ко всему приложению  
✅ Плавные переходы между темами  
✅ Поддержка CSS переменных  
✅ Интеграция с Tailwind CSS  

## Примечания

- Выбор темы сохраняется автоматически в localStorage под ключом `statecore_theme`
- Класс добавляется на элемент `<html>` для работы с CSS селекторами
- Для полной поддержки светлой темы может потребоваться обновление компонентов с жёсткими цветовыми значениями
